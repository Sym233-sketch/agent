# 磁带式三维服务树（独立版本）

- 完整入口：`/reels/user.html`，从保留的原版开场进入。
- 直接预览：`/reels/user.html?preview=1#hall`，仅在当前标签页没有档案时使用虚构演示编号建立本地演示档案；不打开主动关怀，不加入共创，不调用模型。
- 上一版：`/atelier/user.html`。原版、社区版、银色版、树状牌面版均未删除或修改。

## 实现

参考用户提供的 Landing Love 截图及 [Luis Bizarro 的作品页面](https://www.landing.love/sites/bizar-3/)。[原站](https://projects.bizar.ro/)当前提供项目归档与 Cassettes 客户端入口。本版本不下载或运行其客户端，不复用作者的模型、贴图或品牌标识。

使用 Three.js 0.186.1 构建真实 WebGL 三维场景：七盘带实体厚度、双转轴、镂空面板、螺钉和独立贴纸的磁带模型；三条主分支及三维线缆连接服务入口。模型、环境反射及标签均由本地代码生成。

拖动时直接控制镜头，松手后阻尼减速。可点击模型进入对应服务，也可使用底部按钮或键盘。暂停动画与系统减少动态效果偏好均受支持。手机一次聚焦一条分支，保留全部服务的快捷入口。WebGL 不可用时保留原有可操作的树状导航。

业务控制器及服务目录来自已保存的上一版；仅修改呈现层和明确的演示预览入口。政策来源、授权、脱敏、共创和服务登记流程继续使用原有实现。未自动提交事项、订阅提醒或调用外部人工渠道。点击反馈音保持原配置。

## 维护

执行 `node scripts/build-reels-variant.cjs` 从上一版刷新共享页面和控制器，仅写入 `public/reels/`，不会覆盖 `public/atelier/`。然后检查本目录的三维渲染文件。

`vendor/` 中的 Three.js 模块来自官方 npm 包 `three@0.186.1`，保留 MIT 许可证。入口使用本地模块，运行时不依赖第三方 CDN。

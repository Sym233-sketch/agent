# 树状服务图谱：独立预览

入口：`/atelier/user.html`。保留原版开场；完成引导后进入树状服务图谱。

原版 `/user.html`、政府工作台、`/community/`、`/modern/` 均保留。此目录未替换默认入口，也未发布到 GitHub。

## 布局与交互

- 一个生活起点，三条主分支，六个可进入的服务牌面。
- SVG 连线和牌面在同一空间中移动；经过分支时描亮路径，主节点支持收起和展开。
- 打开牌面时由原位置放大为阅读页面，服务树退到背景；返回时收回原分支。
- 原开场的 WebGL 场景继续作为环境。动效可暂停，并跟随系统减少动态效果的偏好。
- 窄屏使用纵向分支，保留层级与连线；详情在独立阅读面中呈现。
- 原点击音效保持木扣与双音的组合及约 45% 音量。

## 参考与实现范围

实际查看了 Landing Love 收录的 [Diagram](https://www.landing.love/sites/diagram/) 和 [Huly](https://www.landing.love/sites/huly/) 的公开画面，并读取了 [Huly 原站](https://huly.io/) 的公开过渡样式。参考节点关系、空间层次、光路和金属边缘。

本次环境未能正常播放 Landing Love 的完整录屏，因此不声称复现了录屏中的完整时间线。树状导航、连线光流、牌面放大与收回均为本地实现；未复制参考站的图片、视频或代码资产。

## 业务与维护

`tree.js` / `tree.css` 负责空间导航和视觉。`user.js` 由当前主线居民控制器生成，只替换外层渲染和入口路由；原有资料脱敏、授权、政策来源、消息、共创逻辑继续使用。服务目录通过同源页面复用 `/services.js`，不会自动登记提醒或提交申请。

主线居民控制器更新后，执行 `node scripts/build-tree-variant.cjs`，重新生成此目录的入口、居民控制器和服务目录入口。生成器只写入本目录，匹配不到预期代码时会停止，需人工核对。不要直接修改生成的 `user.js`。

预览资料仅使用虚构演示编号。私有数据位于仓库外的本地预览数据目录；不使用真实 API 额度验证界面。

# 空间相册版

直接预览：`/album/user.html?preview=1#hall`。完整开场：`/album/user.html`。

页面仅保留品牌、档案入口、一个标题、六张照片与暂停图标。服务名称直接印在相纸下沿；不显示分组、操作注释、重复入口、侧栏、中心装饰、连线或状态文案。真实摄影替换了上一版的程序化形象。

六张相片默认沿立体轨道缓慢环绕。浏览器原生三维变换提供透视、前后遮挡与相纸厚度；没有第二套 WebGL 渲染循环。悬停或键盘聚焦时停留，并把该相片带到前层，方便辨认和选择。拖动可调整环绕位置；系统减少动态效果与暂停图标均受支持。点击照片继续进入原有业务，之前的所有版本均独立保留。

图片均为网上查找的真实摄影，并复用此前背景素材库中的家庭陪伴、牵手与相互支持照片。照片已下载到本目录，不依赖运行时访问第三方图片服务器。作者、原始页面与授权链接见 [photos/sources.json](photos/sources.json)。它们是服务主题的配图。

`node scripts/build-album-variant.cjs` 仅刷新本版本的共享页面和业务控制器；`node scripts/fetch-album-photos.cjs` 只在缺少素材时下载照片。原有政府端、居民端、各实验版本与开场均保留。此轮为本地预览，未上传 GitHub。

验证：66 项既有测试与全量 JavaScript 语法检查通过；无操作时六张相片的位置持续变化，暂停后位置保持稳定；实际点击家庭照片进入补贴分类，政策照片可打开原有政策库。1363×871 与 390×844 的页面均无横向溢出，六张本地照片全部加载。原始界面 13 个文件哈希不变，旧版目录无差异。

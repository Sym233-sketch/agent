# 独立界面预览

原有 `public/user.html`、`public/workbench.html`、业务脚本、动态欢迎页与音效均保留。

- `preview.html`：新版与原版对照入口。
- `resident.html`：公开的社区服务首页；搜索读取现有 `/api/catalog`，不创建居民档案或调用模型。
- `user.html`：沿用现有登记、政策搜索、消息和先行者功能，增加独立社区主题。
- `index.html`：沿用原有单屏政府工作台，使用独立现代政务主题。
- `services.html`、`agent-settings.html`：现有服务与状态页面的主题副本。

所有政策保留原始标题、发布机关、日期和官方来源；不据展示结果判定资格。
动效包含轻量内容进入、悬停反馈、步骤展开，并遵循系统减少动态效果设置。

版式、留白与细节参考用户提供的 Landing Love、Land-book、Awwwards、One Page Love、Lapa Ninja、21st 和 Siteinspire；体验原则参考 NHS 与 GOV.UK。现有插画和业务逻辑继续复用。

# 主题选项自动环绕版

直接预览：`/orbit/user.html?preview=1#hall`。完整开场：`/orbit/user.html`。

本版本按用户对 [Luis Bizarro 参考作品](https://projects.bizar.ro/) 的说明实现自动缓慢环绕的三维选择场景，不复刻参考作品的磁带物件。六个服务入口分别使用爱心托手、补贴礼盒、政策文件与放大镜、共创书写、信封、人工协助形象；原有服务层级通过三组空间连接保持。

打开后无需拖动，选项默认自动沿立体轨道缓慢绕行。悬停或键盘聚焦时停留，离开后自动继续；拖动仅用于调整视角。服务名称始终面向用户，选项和底部快捷入口均可进入原有业务。打开详情时暂停场景运动，返回后延续。系统减少动态效果的偏好与手动暂停均受支持。

手机按服务分支显示两个环绕选项，底部保留全部入口；三维环境不可用时保留可操作的树状导航。

`/atelier/` 树状牌面版、`/reels/` 实验版与其他原始界面均未修改。三维运行库复用已保存的 `../reels/vendor/` 中的 Three.js 0.186.1（MIT）；新形象、轨道与动效均为本地实现。业务控制器沿用前一版，仅在明确的直接预览参数下使用虚构演示档案，不开启主动关怀，不加入共创，不消耗模型 API 额度。

执行 `node scripts/build-orbit-variant.cjs` 可刷新共享控制器和页面，仅写入本目录。此轮为独立本地预览，未上传 GitHub。

已验证：66 项既有测试通过，JavaScript 全量语法检查通过；无拖动时选项位置持续变化，暂停后位置保持稳定；实际点击画布中的爱心可进入关怀服务，政策入口可打开原有查询；390px 手机视口无横向溢出，分支切换和全部六个快捷入口可用。原始界面的 13 个文件哈希与修改前一致，既有各独立版本无差异。

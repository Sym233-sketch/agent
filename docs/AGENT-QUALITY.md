# Agent 检索、审稿与填写质量

本次迭代保留 DeepSeek 单模型、现有免费部署和最终本人确认流程，不新增向量接口、外部数据库或后台付费任务。

## 政策检索

`server/policy-retrieval.cjs` 为已核验文件构建中文倒排索引，结合 BM25、标题及摘要匹配、生活用语扩展和 RRF 排序。命中的正文段落返回原始字符范围，可与全文逐字核对。筛选和分页先计算真实总数，再提取当页段落；同一索引供大厅搜索与 Agent 工具使用。

个人推送的授权、明确需求、拒绝推荐等规则仍独立执行。检索命中不等于资格判断。当前实际官方文件数量由 `/api/policy-dataset` 返回；性能评测中的合成文档不进入政策库。

通过公开搜索取得并读取的政府发布页，会进入可复用的显式检索索引；来源正文更新后索引会重建。这些网页不会自动成为推送或资格依据。用户直接提供且公开性未确认的链接不加入跨用户检索。

参考开源实现思路，未引入其运行时或复制业务代码：

- [pgvector 的混合检索和 RRF 示例](https://github.com/pgvector/pgvector-python/blob/master/examples/hybrid_search/rrf.py)
- [RAGFlow 的检索、分段、筛选和重排序说明](https://github.com/infiniflow/ragflow/blob/main/docs/basics/rag.md)

## 语义审稿

按原文件分段，每段最多 8000 字符、重叠 240 字符，每次最多 12 段，并发最多 2 段。返回每份文件实际成功核查的范围、摘要哈希、失败段落和未覆盖字符数；超大文件不会被报告为全文审完。常见错字与财务核算仍由程序执行。

修改建议须在原文件中逐字定位。重复句必须区分具体位置，不能默认为第一处。金额、期限、资格、权利义务改变，以及同一原句的冲突建议，只作为待核实提示，不提供直接应用。每次应用都核对文件版本，剩余问题按真实字符位移更新；旧语义结论标记为待复核。

官方资料查证按问题提取相关原文段落，而非只读取前 11000 字符。引文仍逐字核验；模型摘要中的量化结论没有引文支持时会被替换为待核实说明。草案不会标为已生效文件。

## 对话与自动填写

对话状态记录已知信息、拒答字段、仅咨询或暂停意图，告诉模型当前是否需要追问；不增加额外模型调用。自动填写除核对原话，还拒绝把假设、提问、更正前的值、家属职业或收入写成本人事实。未知项留空；最终提交继续要求本人确认。

## 2026-10-27：人物、条件与事项连续性

- 人物与事件按分句判断本人、孩子及父母，区分已经入学与准备入学、肯定与否定、本人经历与假设或第三人的情况。职业中含“小学教师”不会再屏蔽下一句孩子入学的需要。多个事件保留关联记录，但当前一件事只展示一个主事件。
- 官方快照增至 20 份，其中新增 4 份上海市或普陀区公开原文。全国、城市及区县适用范围分开；招生和年度预算按目标年份筛选，未来生效、过期、草案与有证据替代的旧版不进入默认推荐。`versionProof` 必须逐字对应同一政策的新原文，才能标记旧版被替代；不能仅凭发布日期认定旧版废止。未知效力继续标为未知。
- 事项的条件逐项返回已有信息、缺失信息、外部认定要求或不一致，并附官方原句及字符位置。家长年龄不会充当学生年龄，收入数额不会直接换算为困难资格，否定参加意愿不会被当成自愿。不输出正式审批结论。
- 审稿增加同名事项的跨章节、跨文件年龄、材料及收费表述对照。不同项目、特殊群体、年龄上下限分别处理；界面可打开两处原文。这些差异只供人工核对，不提供一键改变政策条件的动作。检查范围限于明确可抽取的规则，不宣称理解所有隐含法律关系。

## 事项记忆、恢复与观测

“资料与记忆”可查看本事项的自动填写资料、删除字段并选择不再询问，也可恢复允许询问。拒答独立保存，超过最近聊天窗口仍有效；现有历史中的明确拒答会迁移。删除后不会从个人档案补回该字段，当前相互包含的填写事实与表单值一并清理；用户后来明确提供或在表格直接修改，可重新授权该字段。聊天及历史回执保留，账户删除会清除其事项与任务数据。虚构业务固定地区不作为本人资料删除。

每个请求保留步骤、结果状态、耗时和重试次数；同一请求编号不能改成另一条消息。失败重试仅复用本事项已完成且十分钟以内的只读检索或原文读取；填写动作在事务回滚后重新验证，成功请求直接返回已有结果。缓存不跨居民共享，成功后清除中间缓存。已完成的准备稿不冒充提交，最后一步仍由本人点击确认。

记录每轮模型和工具调用数、耗时、已复用步骤及模型实际返回的输入、输出和缓存 token。接口没有返回用量时 `reported=false`，不将未知用量宣传为免费或估算成真实账单。免费 Render 实例没有新增持久磁盘，因此服务存储重置时仍可能丢失事项，不能保证跨重启永久恢复。

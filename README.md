# 民策通 · 政策共创与主动关怀 Agent

面向政府端与居民端的桌面 Web 原型。围绕“政策找人”串联发布前征询、政策送达、变化线索确认、官方文件检索和辅助材料准备。

## 快速运行

需要 **Node.js 22.9 或更新版本**。不依赖第三方 npm 包，无需安装依赖。

```powershell
git clone https://github.com/Sym233-sketch/agent.git
cd agent
node --env-file-if-exists=.env server/index.cjs
```

- 政府端：http://127.0.0.1:5173/#policy
- 居民端：http://127.0.0.1:5173/user.html
- 模型配置：http://127.0.0.1:5173/agent-settings.html

## 配置模型

推荐在模型配置页选择 **DeepSeek / deepseek-flash** 并填写自己的 API key，保存后测试连接。复杂审稿可选择低强度思考，或手动切换 Pro。也保留 OpenAI mini / nano 接入。

通过配置页填写的密钥只存于后端进程内存，服务重启后需重新填写；不会回传前端或写入居民数据。也可以复制 `.env.example` 为 `.env` 后在本机配置环境变量，`.env` 已被 Git 忽略。仓库不包含任何可用 API 密钥、居民档案、访问令牌或聊天记录。

居民的聊天与后台分析分别授权，且绑定所选模型服务商。切换服务商后，需要重新确认相应授权。联网搜索默认关闭，可在配置页开启；模型和搜索请求可能收费。默认每次进程运行允许 30 次 API 请求（包含独立搜索），这不是金额预算。

官方资料：[DeepSeek 模型与价格](https://api-docs.deepseek.com/quick_start/pricing/) · [Responses API](https://api-docs.deepseek.com/guides/responses_api/) · [Search API](https://api-docs.deepseek.com/guides/search/)

## 主要流程

1. **发布前共创**：居民登记虚构服务档案，自愿加入先行者计划；政府端匹配相关参与者，确认后递送完整草案，用户意见回传政府端。
2. **政策审稿**：程序进行精确金额核算、合计与常见用字检查；模型识别语义问题，修改建议定位原文，经用户核对后应用。
3. **主动关怀**：通过标注为演示的生活变化事件触发消息；获得对应授权后，Agent 生成真实模型关怀，先了解实际影响，始终提供人工入口。
4. **搜集文件**：DeepSeek 独立搜索 API 配合政府域名过滤与 HTML 原文读取；仅将真实返回的来源交给用户，搜索摘要不能代替政策原文。
5. **辅助填写**：从已读取原文提取有证据的字段，或明确生成非官方通用草稿；未知项留空，敏感身份字段仅在浏览器回填，逐项确认后下载。

政府端与居民端通过同一 Node.js 服务和 SSE 实时互通。文件保存发布时快照，支持已读、回复及重复发布去重。

## 演示与真实能力边界

- 支持实际 DeepSeek / OpenAI 模型调用与工具执行；未配置密钥时明确提示，规则检查不会冒充 LLM。
- 银行、实名核验、家庭登记、真实补助发放均**未接入**。填写银行卡不代表获得银行查询能力；无记录不代表没有问题，单一事件不用于认定困难或补助资格。
- 当前读取官方 HTML，保留 PDF / Word 附件链接；尚未解析或填写附件原件。下载的是辅助 HTML 草稿，不自动提交、签名、支付或承诺待遇。
- 人工协助目前在本机创建接手任务，没有真实人员或热线接入。
- 主动帮扶页面仍含明确标注的预置流程样例；真实 Agent 工具入口位于政府端政策页与居民消息页。
- 服务只监听 `127.0.0.1`，是本机开发原型，尚无正式双端账户权限体系；不应直接开放公网或输入真实敏感资料。

## 目录

```text
public/          政府端、居民端、模型配置及虚构政策文件
server/index.cjs 本机 HTTP 服务、共享消息与 SSE
server/agent/    模型适配、工具调度、核算、官方文件与草稿
tests/           不消耗 API 额度的单元测试
scripts/         JavaScript 语法检查
data/            首次运行自动生成的本地状态（不提交）
```

## 验证

```powershell
node --test tests/agent.test.cjs tests/deepseek.test.cjs
node scripts/check.cjs
```

也可使用 `npm start`、`npm test` 和 `npm run check` 这些等价命令。测试覆盖金额计算、无数据判断、政府域名限制、模型工具协议、服务商密钥隔离、搜索过滤、草稿归属和授权。单元测试使用模拟网络响应，不会调用付费 API。开发阶段另已通过实际 DeepSeek 调用验证审稿、匹配、主动关怀、搜索和待确认草稿；实际模型效果与费用仍取决于账号和输入。

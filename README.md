# 民策通 · 政策共创与主动关怀 Agent

面向政府端与居民端的桌面 Web 原型。政府端使用固定一屏的分步工作台，像演示文稿一样切换“导入材料 → 材料审查 → 确认发布 → 检索与递送”，无需上下滚动主页面。

政府端默认采用独立的银蓝莫比乌斯带状曲面，与民生端保持相近的深色三维材质，但使用不同的几何模型与运动。进入审查、发布与检索后，背景自动降低亮度。正文与财报保留浅色阅读区域，材料导入、人工核对、发布、先行者检索及递送沿用现有流程。右上角“对照原版”可切换原有界面并保留当前任务，也可用 `?design=classic` 直接访问。图形使用本地 WebGL 网格，无外部图像或模型依赖；支持减少动态效果与无 WebGL 时的静态回退。

Word / Excel / PDF 拖入后自动转换并审查，点击问题定位正文或单元格，确认后应用修改并导出修订稿。居民端围绕“为你 → 找红通 → 我的进度”组织政策推荐、对话准备与本人确认；搜索、提醒、共创和探索视图按场景展开。

## 快速运行

**与朋友线上共创：** 使用 [Render 部署说明](DEPLOYMENT.md) 部署同一套政府端、居民端与模型后端。GitHub `main` 更新后自动构建，构建检查通过才会发布新版。当前选择免费演示：服务会休眠，重启或部署后演示数据可能丢失。`127.0.0.1` 链接仅用于本机开发，不能分享给其他电脑。线上部署完成后使用 Render 实际生成的 HTTPS 地址；此仓库包含部署配置不代表站点已经上线。

现有线上入口：[共创站](https://mincetong-agent.onrender.com/team.html) · [政府端](https://mincetong-agent.onrender.com/#policy) · [居民端](https://mincetong-agent.onrender.com/user.html) · [模型配置](https://mincetong-agent.onrender.com/agent-settings.html)。无需共创口令，可直接访问。当前运行版本可在共创站中核对。

需要 **Node.js 22.13 或更新版本，推荐 Node.js 24**。首次运行安装文档解析依赖；SheetJS 官方构建已保存在 `vendor/`，运行时不依赖外部 CDN。

```powershell
git clone https://github.com/Sym233-sketch/agent.git
cd agent
npm install
npm start
```

## 界面与关怀素材

居民主入口 `/user.html` 与 `/resident.html` 共用同一控制器和三栏导航：**为你、找红通、我的进度**。推荐政策可以直接交给红通解读；提醒里的办理请求回到同一个对话；待核对资料和虚拟回执集中在进度页。完整结构见 [产品结构说明](docs/PRODUCT-STRUCTURE.md)。

服务图谱、立体空间作为“我的 → 探索与更多”中的展示选项保留，旧 `/atelier/user.html` 与 `/titanium/user.html` 链接继续可用。不要运行历史展示生成器覆盖统一主入口。

政府端、旧展示视图和模型配置页采用清晰的中文字体、开敞纸页曲线与蓝黄浅青配色，加入鲜红爱心及抽象蜡笔涂鸦。老人插画采用短手臂修订版。页面切换提供轻动效，并遵循系统“减少动态效果”偏好。

旧展示视图中的 8 张真实摄影仅在栏目或步骤切换时轮换，输入和阅读时保持背景稳定。照片通过 Unsplash CDN 加载，需要网络；作者、原图和许可可从页面的“背景素材”入口查看，或直接访问 `/care-library.html`。涂鸦文件随仓库提供。详见 [界面与素材说明](DESIGN-NOTES.md)。

## 点击音效

页面仅使用“木叩双音”作为点击反馈，融合木叩的温和起音与双音的清亮回应，总长约 130 毫秒，音量固定为 45%。页面不显示音效设置入口或音量面板，也不读取旧版音量设置。声音仅在主动点击时播放，鼠标移动和悬停不会发声；音效由浏览器本机合成，不需要联网或调用付费接口。

## 配置模型

模型服务固定使用 **DeepSeek / deepseek-flash**，API 与官方文件搜索始终启用，没有服务商、模型、开关或累计调用上限选项。每轮工具步骤限制仍保留，防止单次请求循环。

线上在 Render 服务的 Environment 中设置 `DEEPSEEK_API_KEY`，重启和部署后自动加载；本机开发在被 Git 忽略的 `.env` 中配置。模型状态页只展示连接情况，不接收或回显密钥。密钥不写入仓库、浏览器或居民数据。

居民发送消息时由 DeepSeek 处理脱敏标签和聊天；页面在发送入口说明用途。后台主动关怀仍需居民单独授权。模型和独立搜索请求由 DeepSeek 按实际使用计费。

官方资料：[DeepSeek 模型与价格](https://api-docs.deepseek.com/quick_start/pricing/) · [Responses API](https://api-docs.deepseek.com/guides/responses_api/) · [Search API](https://api-docs.deepseek.com/guides/search/)

## 主要流程

1. **发布前共创**：居民登记虚构服务档案，自愿加入先行者计划；工作人员先审核并确认发布正文快照，系统自动检索相关参与者，再由工作人员选择并确认递送完整草案，居民的已读与意见回传政府端。
2. **政策审稿与财报核对**：直接拖入 `.doc/.docx`、`.xls/.xlsx/.csv`，自动提取正文、工作表、公式与单元格来源；程序核对数量乘单价、合计及可识别公式，比较政策金额与财报合计；模型识别语义问题。点击问题定位原文，修改建议经用户核对后应用，相关合计重新计算。
3. **主动关怀**：通过标注为演示的生活变化事件触发消息；获得对应授权后，Agent 生成真实模型关怀，先了解实际影响，始终提供人工入口。
4. **搜集文件**：DeepSeek 独立搜索 API 配合政府域名过滤与 HTML 原文读取；仅将真实返回的来源交给用户，搜索摘要不能代替政策原文。
5. **辅助填写**：从已读取原文提取有证据的字段，或明确生成非官方通用草稿；未知项留空，敏感身份字段仅在浏览器回填，逐项确认后下载。

政府端与居民端通过同一 Node.js 服务和 SSE 实时互通。发布保存审核报告、正文版本与完整正文快照，支持已读、回复及发布/递送请求去重。修改正文后须重新审查，过期政策不能发布或递送。

自动检索不自动发送：匹配状态与候选结果持久保存，可从“服务跟进 → 政策送达与群众回复”继续操作。模型失败时明确标明标签候选与降级原因；服务重启中断的任务可人工重试。检索会筛查全部已加入计划者的标签与授权，模型最多复核前120位相关候选和前18000字符，其余标签候选仍保留供人工核对。递送前复核参与状态、授权与检索版本；档案或授权变化须重新匹配。政策通知还需要居民开启主动消息授权。

## 演示与真实能力边界

- 支持实际 DeepSeek 模型调用与工具执行；未配置密钥时明确提示，规则检查不会冒充 LLM。
- 银行、实名核验、家庭登记、真实补助发放均**未接入**。填写银行卡不代表获得银行查询能力；无记录不代表没有问题，单一事件不用于认定困难或补助资格。
- 政府端文件导入支持 Word 正文与 Excel 工作表。Word 修订稿重新排版为 DOCX，Excel 修订稿输出为 XLSX，不保证保留复杂 Office 版式。扫描图片、加密文件与宏不在转换范围。单文件最多12MB，单表最多3000行/60列。
- 财务检查覆盖可识别金额列、基础算术、单列 SUM 和部分跨表引用；未支持的函数、循环引用、缺失缓存及无法识别的表头明确提示，不算作核对通过。跨文件金额差异仍需确认口径。
- 官方网页读取支持 HTML，保留 PDF / Word 附件链接；尚未自动下载并填写这些附件原件。居民端下载的是辅助 HTML 草稿，不自动提交、签名、支付或承诺待遇。
- 人工协助目前在本机创建接手任务，没有真实人员或热线接入。
- 政府端右上角的消息入口保留送达回执、居民回复、演示关怀事件与人工任务；主工作台仅聚焦文件审查、匹配与递送。
- 默认开发模式只监听 `127.0.0.1`。线上共创模式保留 HTTPS 来源限制，默认不需要共创口令，访问者共享演示管理权限；尚无正式双端账户权限体系，只使用虚构数据。

## PDF 与联网审稿查证

政策审稿支持拖入 PDF（单份12MB、最多100页），自动提取正文、保留原页码并参与同一审稿和先行者匹配流程。全扫描件需先 OCR；混合文件会列出未读页面。PDF 表格按文字审核，不冒充 Excel 公式核对。PDF 原件可从审查依据弹窗打开，确认的修订正文导出为 DOCX，不会覆盖原 PDF 或保留其签章效力。

问题卡片点击“查官方依据”，确认检索词、地区和日期后启动真实联网检索。需要模型配置页启用搜索并配置可用 API 密钥。工具只保留 HTTPS gov.cn 候选，读取原 HTML / PDF 正文，再由模型核对；引文必须与已读取原文逐字匹配。显示原文链接、读取时间和未读取来源，不把搜索摘要充当证据。结果仅提供参考，证据不足时保留待核实，查证不会自动改写政策。每次通常消耗1次搜索和1次模型请求，计入现有请求上限。尚未接入扫描件 OCR。

## 政府端：上传审查

每组将同名 DOCX 与 XLSX 一起导入政府工作台。三组分别为养老助餐、就业服务、教育服务。征询稿中保留一个可核对的表达或预算问题，方便展示问题定位、财务核算和工作人员确认。其依据仅作主题参考，文件正文由项目编写。
